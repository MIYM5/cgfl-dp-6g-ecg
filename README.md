# CGFL: channel-aware gradient sparsification with record-level DP for federated learning over 6G uplinks

[![DOI](https://zenodo.org/badge/1461663079.svg)](https://doi.org/10.5281/zenodo.24319337)

Code, results and audit scripts for a research manuscript on channel-aware gradient sparsification with
record-level differential privacy for federated learning over 6G uplinks, evaluated on ECG classification.

## Contents
| File | Purpose |
|---|---|
| `cgfl.py` | Everything: data preparation, channel model, CGFL and baselines, DP-SGD with RDP accounting, experiment grids, summaries |
| `results/` | One JSON per run (445 runs): configuration, noise multiplier, test metrics, per-round history |
| `fig_data/` | CSV files read by the paper's charts (pgfplots), generated by `make_fig_data.py` |
| `audit_tables.py` | Recomputes every cell of the paper's result tables from `results/` and flags mismatches |
| `make_fig_data.py` | Writes the data behind every chart of the paper (`fig_data/*.csv`) from `results/` |
| `audit_claims.py` | Recomputes the pooled in-text statistics (53 matched pairs, CI, sign test, noise multipliers) |
| `test_privacy.py` | Privacy checks: accountant vs. Opacus, clipping of masked per-example gradients, noise only on masked coordinates |
| `repro_check.py` | Compares freshly re-run results with the archived ones |
| `wireless_verify.py` | Re-derives Table 2 (wireless baselines) and the Section VI proxy statistics from the code |
| `cgfl_rerun_check.ipynb` | Kaggle notebook: GPU re-run of two archived runs + comparison |
| `requirements.txt` | Python dependencies |

## Data
* PTB-XL v1.0.3 (PhysioNet): `ptbxl_database.csv`, `scp_statements.csv`, `records100/`.
* PhysioNet/Computing in Cardiology Challenge 2021 training data (six institutions).

## Quick start
```bash
pip install -r requirements.txt
python cgfl.py run --synthetic --T 3 --N 4 --part 1.0 --device cpu --results smoke --ckpt smoke_ck   # 1-min smoke test, no data
python cgfl.py prep    --root <ptbxl dir> --out ptbxl100.npz             # 100-Hz signals, folds, train-only normalisation
python cgfl.py prep_ml --root <ptbxl dir> --out ptbxl_ml.npz            # 5-superclass and 44-statement multi-label targets
python cgfl.py prep_cinc --root <cinc2021 dir> --out cinc2021.npz       # six institutions, per-site 80/10/10 split
```

## Reproducing each table
Every experiment is a *stage*; `grid` runs it (skipping finished runs, resuming from checkpoints, `--shard i/n`
for parallel GPUs) and `summarize` prints the aggregated table. All reported runs use `--lr_dp 0.5` (the default).

| Paper table | Stage(s) | Extra arguments |
|---|---|---|
| Main results | `main` | |
| Privacy budget × rounds | `eps_T` | |
| Sensitivity | `ablation` | |
| Scale, heterogeneity, channel | `scale`, `channel` | |
| External baselines | `external` | |
| Default vs. selected configuration | `best`, then `best_confirm` | |
| Superdiagnostic multi-label | `multilabel` | `--labels ptbxl_ml.npz` |
| 44 diagnostic statements | `diag` | `--labels ptbxl_ml.npz` |
| CinC 2021 | `cinc`, `agg_cinc` | `--data cinc2021.npz` |
| Residual network | `resnet_tune`, then `resnet` | |
| Normalised aggregation | `agg`, `agg_cinc` | |

```bash
python cgfl.py grid      --stage main --data ptbxl100.npz --results results --device cuda:0
python cgfl.py summarize --stage main --data ptbxl100.npz --results results
```

## Version 1.1 additions
All new options default to the v1.0 behaviour, so every v1.0 run ID and result is unchanged.

| Option / command | What it does |
|---|---|
| `--method noiseaware` (`--na_sref`, `--na_a`) | Noise-aware retention: each client sends the smaller of its rate cap and the retention its DP noise-to-signal ratio justifies; public inputs only |
| `--method wei` (`--wei_V`) | Baseline after Wei et al. (2024): per-client rate by drift-plus-penalty with average-delay queues; random mask fixed before local training; 1-bit-per-parameter mask counted in the payload |
| `--method cheng --mask topk --blur B` | Baseline after Cheng et al. (2022): bounded-local-update regularisation and sparsification, one ratio for all clients |
| `--agg damped --agg_mu M` | Damped per-coordinate normalisation between weighted (M = 1) and fully normalised (M = 0) aggregation |
| `--server_mom B` | Server momentum (use `--server_lr 1-B`) |
| `--smin_size 1` | Size-aware floor for small clients |
| `--csi_err E --csi_backoff_db X --harq_max K` | Imperfect CSI (MMSE estimate), rate back-off, HARQ retransmissions on fresh fading, drop after K attempts |
| `--mq_every K` | Measures every K rounds the gradient energy kept by the public mask vs. a random mask (validation data) |
| `resplit_cinc` | Patient-wise split of the PTB-XL institution inside the CinC-2021 file (`--cinc_split patient`) |
| saved per run | `<id>_probs.npz` (validation and test probabilities); multi-label F1 at validation-tuned thresholds; per-hospital AUC on PTB-XL |

Settings used in the paper that differ from the option defaults: `--na_sref 0.5 --na_a 0.25` (selected on validation data), `--wei_V 0.1`, `--blur 0.01`, `--agg_mu 0.5`, `--server_mom 0.9 --server_lr 0.1`, `--csi_backoff_db 1.0`. The channel code uses a 0 dB noise figure over the 100 MHz carrier, which gives the same noise power (−94 dBm) as the paper's 10 dB over the 10 MHz sub-band.

Version 1.1 statistics and tables (all 880 result files are in `results/`):

```bash
python analysis_v11.py . results data/ptbxl_ml.npz analysis_v11.json   # 20-seed non-inferiority tests, baselines, remedies, CSI, mask quality, clinical metrics, end-to-end time
```

## Re-running a sample and comparing
```bash
python cgfl.py run --data ptbxl100.npz --method capacity --dp record --mask public --seed 1 --results rerun --ckpt rerun_ck
python cgfl.py run --data ptbxl100.npz --method fedavg   --dp record                --seed 1 --results rerun --ckpt rerun_ck
python repro_check.py results rerun
```
The noise multiplier, data volume and uplink time are deterministic given the seed. Test AUC can differ by a
few thousandths because GPU kernels are not bit-wise deterministic.

## Notes
* Privacy: per-example clipping, Gaussian noise on the public mask only, Poisson sampling with rate
  `q_k = min(B/n_k, 0.5)`, exact RDP of the subsampled Gaussian over integer orders 2–256, conversion of
  Balle et al. (2020). The accountant agrees with Opacus to four decimals of ε.
* Index cost: Top-k indices cost `ceil(log2 d)` bits (18 for the CNN). Runs archived before this was
  set in code stored 32-bit indices; the audit and comparison scripts rescale those payloads by `(32+18)/64`,
  which is how the paper's numbers were computed.
* `wireless_verify.py` regenerates, without a GPU, the channel draws, schedules and retention ratios of the
  53 matched runs (the regenerated uplink times equal the logged ones to 1e-15), recomputes the wireless
  baselines of Table 2 and the gradient-proxy statistics of Section VI. Runtime about 10 minutes on a CPU:
  `python wireless_verify.py . results ptbxl_ml.npz wireless_verify.json`
* `cgfl_rerun_check.ipynb` re-runs two archived configurations on a Kaggle T4 and compares them.
